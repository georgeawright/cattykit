# Papers

This Directory contains articles that relate to the work in this repository.
Articles are written in markdown so that they can be rendered in a web browser,
but they can also be converted into a latex pdf using pandoc and latexmk.

## PDF generation

To convert a paper from markdown into a pdf file, run this command from inside this directory:

``` bash
make PAPER=directory-name
```

Replace `directory-name` with the name of the directory that contains a `paper.md` file.
